## Softbank 和 IIJ 两条线路，差别在哪

一句话结论：电信用户优先 Softbank 版，IIJ 版的电信回程实测口碑不佳；Softbank 版三网都走 SoftBank，表现更均衡。

第三方线路监测数据把两条线路的区别说得很具体：

- **Softbank 版**：电信、联通、移动三网回程全部走 SoftBank，与 v.ps 东京产品同上游线路。
- **IIJ 版**：电信走 IIJ，联通和移动走 163 / CMI / 4837 这些常规线路。监测简评对 IIJ 版电信方向的原话是“就目前数据来看电信相当糟糕”。

所以选线路的决策规则很简单：你的主要用途涉及电信网络访问（比如家宽是电信，经常从国内拉文件），选 Softbank 版；纯挂机下载、做冷备份、不太在意国内访问速度的，IIJ 版哪个档有货买哪个，毕竟配置和价格完全一样。

顺带一提，有第三方评测对绿云东京机房做过测速，电信下载能跑到 100Mbps+，电信 / 联通延迟约 50–80ms，移动稍高、经香港中转。这个成绩放在年付 25 美元的产品上，属于超出价位的水平。

## 25 美元之外，还有哪些隐藏成本和限制

官方标价之外，有三笔账要提前算清楚。

**第一，流量加购在亚太贵得离谱。** 官方加购价是美欧机房 $3/TB/月，亚太机房 $15/TB/月，整整 5 倍。1TB 月流量对备份同步够用，但如果你打算把它当下载机天天跑满，超流量后的补流量成本不低，不如直接升档。

**第二，同价不同量。** 同样是 $25 / $45 / $80 三档，美欧机房的流量是 3TB / 6TB / 10TB，日本和新加坡只有一半多一点（1TB / 2TB / 4TB），0.5TB 档差三倍、2TB 档差两倍半。这多出来的流量本质上买的是日本机房到国内的线路质量，纯看存储性价比，美国机房更划算。

**第三，加购资源有上限。** 官方允许加购存储（最多 20TB，$5/TB/月）、内存（$3/1GB/月）和 CPU（$3/核/月），但规则是只能在自己已有资源基础上翻倍：4GB 内存的机器最多再加 4GB，CPU 同理。想靠加购把 0.5TB 档堆成高配，行不通。

还有一条写在每个套餐页面上的硬性条款，值得单独拎出来：
